# SA5 V9 冻结版本（2026-11-06）

本目录记录 `sa5_v9_scale_preference_20261105` 的源码、部署权重、训练采样、验证选模、测试结果和诊断证据。上一 GitHub 冻结版本是 [Step5 R2](../v5_step5_r2_frozen_20261102/README.md)，对应提交 `b16ca2318add176e8f9a81101f141f4f8d90f65e`。本目录的 V9 是该实验阶段的版本号，与仓库早期 V2/V4 等版本编号不是同一轮实验编号。

任务为五目标带时间窗车辆路径问题，最小化车辆数、总距离、最大路线完成时间、等待和延误。外层保留 16 方向 MOEA/D 种群；每批先生成子代，再对方向子代执行最多五步破坏—修复与模拟退火接受。

## 部署组成

- 16 个原 R2 方向专家 `direction_00.pt` 至 `direction_15.pt`，与上一版本对应文件字节相同。
- 共享 Controller：22→32→4，868 参数，输出三项模式 logit 偏移和一项 Beta 均值 logit 偏移。
- 四种经典修复器：greedy、regret2、regret3、noisy_greedy，继续使用 ALNS 自适应选择。
- 训练时增加 22→32→1 Critic，769 参数；测试不使用 Critic。
- 最终 Controller 为 `checkpoints/controller/v9_best_gate.pt`，字节等于 `cycle_3.pt`。所有六轮及初始 Controller 检查点保留。

## 已完成运行

|阶段|实例与重复|单次在线预算|实际记录|
|---|---|---:|---|
|训练|fit180 池抽取18个不同IID，每规模6个|180秒|6次三规模联合更新、每次2个PPO epoch，共181360条优化动作|
|验证|45个validation IID×2个检查点|180秒|90次完整搜索，比较第3、6轮|
|V9测试|9个IID×3个搜索seed|117–338秒|27次完整搜索|
|测试对照|roulette与V8各27次|相同逐IID预算|只读复用54份已有报告|
|V9冒烟|每规模1个fit IID|16秒|3次独立技术搜索；不计入训练或27次测试|

训练名义采样预算为3240秒，即54分钟；初始化、模型加载、PPO更新和最终物理审计另行发生。fit180指候选训练池，实际使用18个IID，不是完成180个IID训练。每轮先收集50、150、250各一场180秒数据，再联合更新；规模采集次序与单规模独立优化是两件事。
