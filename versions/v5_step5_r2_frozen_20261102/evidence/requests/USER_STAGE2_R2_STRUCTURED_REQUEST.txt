### 第二步：升级网络头架构——引入轻量路径级表征（Route-Pooling）与三模态结构化破坏动作空间
保持 `pretrained/meta_complete.pt` 的 128D GAT `Encoder`、`context`、`q_history_norm` 冻结热启动不变；升级可训练策略头（`Policy`、`Head`、`CpuHead`）以消除“独立 Gumbel 采样拔不空整条车”和“缓存 `anchor_q` 失配”两大架构瓶颈：

1. **双锚点 `q/N` 线性插值节点缓存（消除 `anchor_q` 失配且不增加 CPU 矩阵乘开销）**：
   - 在每次 GPU `refresh` 时，对同一份冻结 GNN `nodes` 分别在两个固定比例 $\rho_{\text{lo}} = 0.04$ 和 $\rho_{\text{hi}} = 0.25$ 下通过 `film` + `head.node` 计算两组拓扑基础分 `values_lo` 与 `values_hi`（仅 2 次轻量 MLP 前向，不重复跑 GAT），连同 `hidden`、`physical_weights`、`nodes`（训练回放时保留）一起缓存。
   - 在每步采样确定实际 $q$ 后，令 $\lambda_q = \text{clip}\big(\frac{q/N - 0.04}{0.21},\, 0,\, 1\big)$，在 CPU/GPU 上用 $O(N)$ 线性插值得到当步真实规模调制的节点拓扑分：
     $$v(q) = (1 - \lambda_q)\, v_{\text{lo}} + \lambda_q\, v_{\text{hi}}$$
   - 结合当步实时标准化物理残差 $\tilde{\Phi}_{\text{phys}} \in \mathbb{R}^{N \times 5}$ 得到客户节点 logits：
     $$\ell = v(q) + \tilde{\Phi}_{\text{phys}} w_{\text{phys}}$$
     **移除**旧代码中 `/(1 + 0.75 * stall_gate)` 的高温抹平除法，保留停滞期对瓶颈点的区分度（动态 `raw[5:10]` 保持冻结 `context.0` 兼容，同时将当前解相对动态前沿的位置 `(objectives - dynamic_ideal) / dynamic_span` 的均值与最大加权项并入可训练 `q_body / q_film` 的 `state` 输入向量）。

2. **轻量实时路径级聚合分支（Route-Level Pooling，纯向量化，CPU 耗时 `< 30 µs`）**：
   - 对当前解的 $V$ 条非空路径 $r_0, \dots, r_{V-1}$（客户集 $C_m$），在 CPU（`stage2_cpu.py`）和 GPU（`replay_terms`，训练回放记录当步 `routes` 或路径归属索引）上完全一致地计算每条路径的 6 维标准化结构特征 $\phi_m \in \mathbb{R}^6$：
     `[len(C_m)/(N/V), 1 - load(C_m)/capacity, mean_detour(C_m), 1 - mksp_slack(C_m), mean_wait(C_m), mean_tardy(C_m)]`（对 $V$ 条路径做零均值单位方差标准化，`std` 下界 `1e-5`）。
   - 在每个 `Head` 中新增可训练参数 `route_bilinear` $\in \mathbb{R}^{5 \times 6}$（初始化使车辆偏好倾向短路径与高剩余容量、距离偏好倾向高 detour、makespan 偏好倾向 `1 - mksp_slack` 瓶颈路、等待/延误偏好倾向高 wait/tardy）以及 `route_score_scale`（标量，初值 `1.0`）：
     $$\ell^{\text{route}}_m = \text{route\_score\_scale} \cdot \bar{\ell}_m + (w_{\text{pref}}^\top B_{\text{route}} \tilde{\phi}_m), \quad \bar{\ell}_m = \frac{1}{|C_m|} \sum_{c \in C_m} \ell_c$$

3. **三模态结构化破坏动作空间 $(m, u, S)$ 及 100% 精确闭式条件对数似然（彻底废除 250 维全排列 `lp_rank`！）**：
   - 在每个 `Head` 中配置：
     - 模态分类头 `mode_logits`: `Linear(h, 3)`（输入 `q_hidden`，输出 3 种破坏结构模态的 logits，初值权重置零，初值偏置设为 `[0.2, 0.2, -0.2]`，使三种模态初始均有充足探索）；
     - 模态专属连续规模头 `q_mu`: `Linear(h, 3)` 与 `q_kappa`: `Linear(h, 3)`（分别对应 3 个模态的 Beta 分布参数 $\alpha_m, \beta_m$，初值 $\mu = [0.35, 0.40, 0.30], \kappa = 4.0$）。
   - 每步先采样模态 $m \sim \text{Categorical}(\text{softmax}(z_{\text{mode}}))$，再采样 $u \sim \text{Beta}(\alpha_m, \beta_m)$，按模态生成破坏集并计算**严格精确的实际执行动作条件对数概率**（绝不包含未选中尾部节点的排列项！）：
     - **Mode 0（`spatial_cluster`：局部/中尺度空间邻域精修）**：
       - $q_{\max}^{(0)}(N) = \min(\max(12, \lfloor 0.22 N \rfloor), 45)$，$q = \text{clip}(\text{rint}(2 \cdot (q_{\max}^{(0)}/2)^u), 2, N)$。
       - 先用当步 $\ell(q)$ 按**精确 Categorical** $\text{softmax}(\ell)$ 采样锚点 $a \in \{1,\dots,N\}$；
       - 取 `neighbors[a]` 中前 $M = \min(N-1, \max(2(q-1), 16))$ 个近邻客户组成候选集 $\mathcal{C}(a, q)$；
       - **仅在候选集 $\mathcal{C}(a, q)$ 上** 独立注入 Gumbel 噪声无放回抽取有序前 $q-1$ 个近邻 $S_{1..q-1}$，移除集 `removed = [a] + list(S)`。
       - **精确闭式微观对数似然**（链式法则，零近似）：
         $$\log \pi_{\text{micro}}(a, S \mid m=0, q) = \log \text{softmax}(\ell)_a + \sum_{j=1}^{q-1} \left(\ell_{S_j} - \log \sum_{c \in \mathcal{C}(a,q) \setminus \{S_1,\dots,S_{j-1}\}} \exp(\ell_c)\right)$$
         有效选择步数 $|S|_{\text{eff}} = q$。
     - **Mode 1（`bottleneck_global`：全图跨路径瓶颈拔除）**：
       - $q_{\max}^{(1)}(N) = \min(\max(10, \lfloor 0.35 N \rfloor), 75)$，$q = \text{clip}(\text{rint}(3 \cdot (q_{\max}^{(1)}/3)^u), 3, N)$。
       - 在全图 $N$ 个客户上用 $\ell(q)$ 做 Gumbel-Top-$q$ 无放回抽取有序前 $q$ 个客户 $S = (S_1, \dots, S_q)$，`removed = list(S)`。
       - **精确闭式 Plackett-Luce Top-$q$ 边缘对数似然**（只对前 $q$ 个被选节点求和，分母为剩余全图未选集指数和，严禁把后 $N-q$ 个未选节点的排序加进似然！）：
         $$\log \pi_{\text{micro}}(S \mid m=1, q) = \sum_{j=1}^{q} \left(\ell_{S_j} - \log \left(\sum_{c=1}^{N} \exp(\ell_c) - \sum_{r=1}^{j-1} \exp(\ell_{S_r})\right)\right)$$
         有效选择步数 $|S|_{\text{eff}} = q$。
     - **Mode 2（`route_coherent`：整车路径连根拔除与重组——专攻消车与平衡 makespan）**：
       - 设最多拔除整车数 $K_{\max}(V) = \min(V, \max(1, \min(4, \lfloor 0.25 V \rfloor)))$，映射 $K = \text{clip}(1 + \lfloor u \cdot K_{\max}(V) \rfloor,\, 1,\, K_{\max}(V))$，首先按近似估计规模 $\hat{q} = \text{clip}(\text{rint}(K \cdot N / V), 2, N)$ 计算 $\ell(\hat{q})$ 与 $V$ 条路径的 $\ell^{\text{route}}_{0..V-1}$。
       - 在 $V$ 条路径上按 $\ell^{\text{route}}$ 做 Gumbel-Top-$K$ 无放回抽取有序路径 $R = (r_1, \dots, r_K)$。
       - 构造 `removed`：**第一条选中路径 $r_1$ 的全部客户 100% 完整移入 `removed`（绝对保证至少拔空一整辆车！）**；随后依次遍历 $r_2, \dots, r_K$，在总移除数不超过硬上限 $q_{\text{cap}} = \min(\text{rint}(0.45 N), 100)$ 的前提下整条并入（若某条后续路径整条并入会超上限，则按该路径客户在 $\ell(\hat{q})$ 降序截取至 $q_{\text{cap}}$ 后停止，此截断在给定 $(R, \text{routes}, \ell)$ 下完全确定）。实际 $q = |\text{removed}|$。
       - **精确闭式路径级 Plackett-Luce Top-$K$ 对数似然**：
         $$\log \pi_{\text{micro}}(R \mid m=2, K) = \sum_{j=1}^{K} \left(\ell^{\text{route}}_{r_j} - \log \left(\sum_{v=0}^{V-1} \exp(\ell^{\text{route}}_v) - \sum_{p=1}^{j-1} \exp(\ell^{\text{route}}_{r_p})\right)\right)$$
         有效选择步数 $|S|_{\text{eff}} = K$。

### 第三步：解耦双 Ratio PPO 目标 + 早/中/晚三阶段真实收敛状态池 + 去短视信用分配
1. **解耦宏观/微观双 Clipped PPO 目标（彻底杜绝不同维度似然互相挤爆 `clip_epsilon`）**：
   - 宏观对数似然：$\log \pi_{\text{macro}}(m, u) = \log P(m) + \log p_{\text{Beta}}(u; \alpha_m, \beta_m)$，重要性比率：
     $$r_{\text{macro}} = \exp\!\big(\log \pi_{\text{macro}}^{\text{new}} - \log \pi_{\text{macro}}^{\text{old}}\big)$$
   - 微观步均几何比率（除以 $|S|_{\text{eff}}$ 归一化，使 $q=3$ 与 $q=40$、$N=50$ 与 $N=250$ 具有完全一致的信赖域尺度）：
     $$r_{\text{micro}} = \exp\!\left(\frac{\log \pi_{\text{micro}}^{\text{new}} - \log \pi_{\text{micro}}^{\text{old}}}{|S|_{\text{eff}}}\right)$$
   - PPO 损失函数为两者各自独立 clip 之和减去熵正则：
     $$\mathcal{L}_{\text{actor}} = -\min\big(r_{\text{macro}} A, \text{clip}(r_{\text{macro}}, 1-\epsilon, 1+\epsilon) A\big) - \min\big(r_{\text{micro}} A, \text{clip}(r_{\text{micro}}, 1-\epsilon, 1+\epsilon) A\big) - c_H \big(H(m) + 2 H_{\text{Beta}}(u \mid m) + \bar{H}_{\text{micro}}\big)$$
   - 每个 PPO batch 在 `epoch == 0` 必须强校验：`max |r_macro - 1| <= 1e-4` 且 `max |r_micro - 1| <= 1e-4`！
   - 优化器分组：`fast`（`lr = 3e-3`）包含 `q_body`, `q_film`, `mode_logits`, `q_mu`, `q_kappa`；`slow`（`lr = 3e-4`）包含 `film`, `node`, `physical_bilinear`, `route_bilinear`, `route_score_scale`。`meta_step_size` 设为 `0.5`（避免最后一步共享层全量覆盖抖动）。

2. **修复 `stage2_runtime.py` 的“非目标方向零步污染”并构建早/中/晚（Early / Mid / Late）三阶段状态池**：

     - 同时在持久池中利用 4 个 CPU worker 对代表性状态做快速推进，维护 `Early`（初始/高接受率期）、`Mid`（车数已显著下降的中期膝点打磨期）、`Late`（低接受率 `< 15%` 或初始 `stagnation >= 4` 的深水平台期）三类真实起点快照，确保在 Meta 后期与 16 方向 Adaptation 阶段，**至少 50% 的训练组起点来自 `Mid` 与 `Late` 收敛/停滞状态**！
