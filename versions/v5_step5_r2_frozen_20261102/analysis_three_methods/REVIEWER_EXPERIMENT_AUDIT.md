# 最新三方法实验：只读审稿核查

## 核查范围

只核查最新三方法、45IID×20搜索seed、各900份结果（共2700）。MOEA/D–DPR指MODEL_SELECTION最终选定的r2整套方向权重，非r3。主评价仅使用本次三方法共同经验非支配参考的逐seedHV/IGD+。本核查不以其他方法集合的历史汇总判定当前性能，也不修改源码或启动实验。

## 已核实事实

- 2700唯一IID×seed×method记录；全部45IID/20seed完整，无Step4缺失问题。
- 补充分析逐文件检查IID/seed、同seed完整16初始种群、逐IID预算、物理尺度与offset匹配。114–407秒预算一致。
- 每IID汇总三方法×20seed目标档案取共同ND，ideal/nadir来自该ND；每seed档案独立计算HV(ref=1.1^5)/IGD+，不合并seed档案当单次运行。物理尺度在此仅用于近零经验跨度判定；不是HV归一化尺度。
- 三方法最终2700条指标/135个逐IID均值SD，配对精确符号秩p值由SciPy独立复核。Holm6包括三组方法对×两指标，属于事后补充分析。
- 每个规模15IID×20seed=300run；总体45IID等权。表格SD是20个seed的宏观均值间样本SD，不是多次独立训练的SD。
- 最终DPR采用r2：一个训练seed20261024，180FIT(50/150/250各60)，60meta批、每方向20完整PPO批、223330优化转移，约4460.95秒。r3的144meta/每方向90批/824323转移不属于最终900run所用模型。
- 12core×3seed用于r2/r3整套模型选择，最终选r2后统一补齐900。不是按方向挑权重。45IID此前已查看，不称盲测。
- 所有正式测试不做参数优化。20搜索seed属于运行随机性重复，不能声称20独立训练。

## 三组真实机制

1. MOEA/D–ALNS (`heuristic`)：MOEA/D外层，每方向保持ALNS历史；4破坏类型×10预设移除比例档位，轮盘赌更新破坏选项与4修复器权重。比例档位约1/2/5/10/20/30/40/60/80/100%，q=ceil(N×ratio)，并非固定单一q。名称“固定版”只能解释为固定实现/候选档位，不能写成每步固定邻域大小。
2. MOEA/D–ALNS-T (`alns_tuned`)：同一旧MOEA/D源码，4破坏类型×8合法档位（上限60%），仍有轮盘赌反馈。medium配置的decay=.8和max_ratio=.6固定。选参证据为3个合成验证实例、1调参seed、3预声明候选，而非大规模充分调参或SOTA认证。
3. MOEA/D–DPR（r2）：学习三种结构模式及Beta控制的邻域大小、客户/路线有序选择；修复器仍ALNS自适应。Mode2按路线数选择K并优先完整第一条路线，所以q不总是同样的客户数动作。单GNN缓存、当前物理信息更新、CPU头抽样，端到端策略服务时间需计入墙钟。不是端到端直接构造完整解，也不是测试时重训练。

## 框架相同与实现相同必须区分

三组均使用MOEA/D，不能说基线不在MOEA/D框架中。但对这三组实际绑定的源码及r2原始日志核查，以下差异确实存在：

- 旧ALNS/ALNS-T `repo/solver/base_environment.py:41` 与 `outer.py:31`：使用固定offset/scale的加权切比雪夫+0.05加权和。
- 选定r2 `stage2_archive_r2/stage2_repo/solver/base_environment.py:45,51`、`outer.py:244`：档案动态ideal/span，span下界0.05×physical_scale；增加0.001无权重z和及系数1越界惩罚。修复插入、接受评分、分解替换共用该上下文。
- r2 `outer.py:107`另有覆盖_replace：自身独立替换，邻居采用替换前快照判克隆，支配替换，以及非支配改进量排序Top2；旧基线未覆盖该_replace，继承pymoo替换逻辑。
- r2原始`stage2_archive_r2/stage2_evaluation/50-0-0_seed20261024_step5_stage2_retrained.json`含16个dynamic_scalarization_snapshots、真实scalar_snapshot、before/candidate/repair_final_score，表明动态机制是实际执行路径，不只是未使用代码。

这不是把旧性能报告混进当前结论：它是追溯最新三方法统计所读取结果的实际源码绑定。共同预算/初始群/约束保证整体实现比较有意义；它们并不自动保证只有邻域选择一项变化。

## 现有结果可以支持什么

- 在指定三方法经验参考、当前45IID及预算条件下，完整MOEA/D–DPR(r2)的总体HV与IGD+均优于两版ALNS，配对检验Holm6校正后显著。
- 三规模均值领先，但不代表每个IID/每规模每指标均显著。相对ALNS-T，50规模HV校正p=.05114746，IGD+ p=.10699463；150规模两指标p=.33764648；250规模HV p=.18762207，IGD+ p=.01074219。
- r2同时在50/150/250任务上有效运作，属于多规模评测。训练已包含三规模，不能据此声称未见规模外推。
- 原始档案可行性/目标审计及完整配对是优势证据；不声称最优解、SOTA或普适优越。

## 现有结果尚不能单独支持什么

- “提升全部来自学习自适应邻域”：评分尺度、替换策略、破坏集合等也变化，不能仅由完整算法比较分离其贡献。
- “学习邻域大小是主要收益来源”：大小、位置/路线、三模式共同学习，缺少单项干预消融。
- “训练稳定”：一个训练seed，多个搜索seed不等于多次训练。
- “跨规模泛化/新实例盲测”：三规模都用于FIT，12core用于选模型，45例已查看。
- “总体显著证明各目标和所有偏好都改善”：HV/IGD+是解集指标，需具体目标和实际解点解释。

## 审稿补充优先级（仅建议，未执行）

P0 不新增搜索即可做：
- 正式实验表写清两版ALNS都自适应；当前选定为r2；不同方法集合参考的数值不可混用。保留三方法事后Holm6而不当作预注册检验。
- 利用现有raw时间戳/point_events重建相同截止时间的质量—时间曲线，使用固定的一套经验几何；模型服务开销包含在总墙钟。列每规模/每IID效应量、配对差值、异常大差实例和真实同一解的目标。
- 将12模型选择IID与其余33IID分别报告；33IID也已查看，不改称全新盲测。已核算的描述性结果：三方法共同参考下，33IID r2 HV=.72313813，ALNS-T=.68198181；IGD+ .08890638/.12539699。仅为分层描述。
- 固定所有预声明比较的方法/seed/reference，做经验归一化敏感性分析。此前4方法与本次3方法有42/45例经验几何变化，说明不宜选显著的一套报告为唯一证据；本项保持经验前沿口径，不要求改用物理尺度主指标。

P1 若核心论点是“学习邻域机制有效”，最小新增对照：
- 先设计当前完整r2框架中“经典轮盘赌选择”分支：继承同样动态评分、种群替换、修复器、接受、初始群/预算，只改变邻域决策。当前两版ALNS不删除不覆盖，新增分支单独命名。若动作支持集也不同，应明确这是经典决策包对学习决策包，仍非纯神经打分效应。
- 在同一当前框架中采用开发集选定的固定q/N，同时保留其余选择机制，用于检验动态大小贡献；或只关闭学习大小/只关闭学习位置，明确哪些部件不变。冻结权重的干预只证明当前模型对干预敏感，严谨组件贡献需同等训练预算的重训消融，二者分开称呼。
- 不建议把一个同名旧ALNS重复跑一遍，也不要求没有论点关联地堆算法。

P2 若声称学习稳定/泛化：
- 另加独立训练seed（建议总计至少3，属建议而非既有授权），评测完整方法与关键消融；分别统计训练间和搜索间变异。
- 设计真正未用于模型/超参选择的新IID集合，冻结方法后一次性评测三方法；只增加旧45的搜索seed不能替代新IID。
- 若声称跨规模外推，专设未参与训练的规模或留一规模训练实验；若不声称外推，则无需硬加这项。

P3 若声称整个求解器达到先进水平：
- 增加适配同一五目标约束/预算的较强经典改进算法或最相关公开学习方法，先核对应问题支持与迁移成本；标准单目标HGS/PyVRP不能直接当同五目标HV对照。没有这项时，把论点限定为“相对这两种ALNS实现的提升”，不称SOTA。

## 可用于论文的当前结论

在45个实例、每实例20个搜索种子的三方法比较中，完整MOEA/D–DPR(r2)在共同经验参考下取得最高总体HV与最低IGD+，相对两版MOEA/D–ALNS的总体差异经双侧配对Wilcoxon符号秩检验及Holm6校正后显著。该结果说明当前完整实现具有竞争力；学习大小、位置选择及评分/替换机制的独立贡献需用受控消融进一步区分。所有数据已参与既定开发/选择流程的情况应披露。
